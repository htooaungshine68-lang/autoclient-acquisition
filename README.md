At a high level, the system is pretty simple:
- Create a database that hold lead data
- Automate the email setups with Python codes
- Maintain the database, add more cold leads

Now, the system does all the labor works, such as checking the lead’s time zone, any missing fields or whether a contact is worth emailing today or tomorrow.

-- —

If you want to duplicate this client management system and adapt inside your workflow. 

You need to -
- Get the Notion database template.
- Clone this GitHub repository.
- Add the following variables inside your GitHub action secrets.
 - - EMAIL_USER - Your Gmail
 - - NOTION_API_KEY
 - - NOTION_DATABASE_ID
 - - EMAIL_PASS (Your Google App Password)
